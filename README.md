# FEA 悬臂梁 AI 管线：Lesson & Learn 报告

## 1. 项目概述
在云主机上从零搭建一套**不依赖商用软件、完全自包含**的 FEA 结构优化 AI 管线：
- 案例：矩形截面悬臂梁，端部集中力 F=1000N，平面应力问题
- 目标：质量最小；约束：Mises 应力 ≤200MPa、端部挠度 ≤4mm
- 设计变量：梁高 h ∈ [0.02,0.12]m、板厚 t ∈ [0.004,0.02]m
- 技术栈：Python 3.12 + gmsh（真实网格）+ numpy/scipy（自研 CST 求解器）+ Optuna（TPE 优化）+ matplotlib

## 2. 目录结构与五要素落地
```

├── knowledge.py          # Knowledge：材料参数、解析公式、规范门限（显性手册）

├── agent.py              # Agent：状态机调度、容错、迭代控制、历史持久化
├── plotting.py           # 云图与收敛曲线绘制
├── run_pipeline.py       # 主入口
├── skills/
│   ├── base.py           # 统一 IO 协议与错误码
│   ├── s1_problem.py     # 需求解析
│   ├── s2_mesh.py        # 参数化几何+网格（gmsh）
│   ├── s3_bc.py          # 边界条件与耦合加载
│   ├── s4_solver.py      # CST 有限元求解
│   ├── s5_extract.py     # 应力/挠度/质量提取
│   ├── s6_evaluate.py    # 约束评估与惩罚

```
关系：knowledge + knowhow 是底座 → 被封装进各 Skill → Agent 编排 Skill 完成闭环 → 本报告沉淀 Lesson & Learn 并反哺下一轮。

## 3. 运行结果（35 轮）
| 指标 | 最优值 | 限值 | 同尺寸解析解 |
|---|---|---|---|
| 梁高 h | 99.62 mm | — | — |
| 板厚 t | 5.29 mm | — | — |
| 质量 | 4.141 kg | 最小化 | 4.141 kg（一致） |
| 最大 Mises | 104.91 MPa | 200 MPa | 114.2 MPa |
| 端部挠度 | 3.449 mm | 4 mm | 3.709 mm |

- 总样本 35，可行 18，约束违反 16，预检拦截坏样本 1。
- 运行最优质量阶梯下降：9.93 → 5.99 → 5.53 → 4.97 → 4.14 kg。
- **关键工程结论：挠度是主动约束（贴 4mm 边界），应力约束不活跃**，说明细长梁刚度先于强度失效，符合理论预期。

## 4. 开发中真实踩坑与根因（核心 Lesson）
| # | 现象 | 根因 | 修复 | 沉淀的规则 |
|---|---|---|---|---|
| 1 | `UpdateFinishedTrialError` | Optuna `tell()` 后 trial 已结束，再写 user_attr 被拒 | user_attr 写入移到 tell 之前 | 有状态对象先写属性再提交 |
| 2 | S8 `KeyError 'stop'` | `_record` 字段名是 `mass`，S8 却取 `objective`，可行样本出现时异常被兜底吞掉 | 统一字段为 `mass` | 跨模块字段必须单一权威命名 |
| 3 | 日志出现 `%!,(MISSING)` | 提示文本含裸 `%` 字符，被日志格式层误解析 | 去掉 `%`，改中文相对违反量 | 面向日志的文案避免裸格式符 |

> 方法论教训：异常被 BaseSkill 兜底后表现为「字段缺失」而非原始报错，排查时应先回看兜底分支，而不是怀疑调用逻辑。

## 5. 验证证据（不是只看脚本跑通）
1. **解析解对照**：单轮质量与解析完全一致；挠度/应力误差在粗网格约 7–8%，方向为 CST 偏刚，符合单元理论。
2. **网格收敛（h-refinement）**：挠度 14.36→15.06→15.33→15.46mm，单调逼近解析 15.53mm（误差 7.6%→0.5%）。
3. **应力集中现象**：固定端最大应力随加密持续上升（221→266MPa），因约束局部存在应力集中；梁理论 240MPa 是截面平均应力。工程取效应远离约束截面取值或报告截面应力，不能直接拿约束点峰值下结论。

## 6. 新沉淀 / 待回写的 Know-how
- 本类悬臂梁基准网格取 h/4（高向 4 层），固定端加密区 1.5h、加密比 0.5，可直接作为默认模板。
- 几何预检（h/t>25 判高风险）在本轮成功拦截 1 个坏样本，避免无效求解，应保留并前移。
- 失败样本给固定大惩罚（100）而非丢弃，TPE 能稳定避开高风险区域。

## 7. 局限与改进方向
- CST 是常应变单元，偏刚；后续可升级 6 节点二次三角形（LST）或四边形 Q4/Q8 降低网格依赖。
- 当前为 2D 平面应力；可扩展 gmsh 3D 实体网格 + 自研六面体单元，或接入 CalculiX（需可用 apt 源）。
- 优化为单目标；可改 NSGA-II 输出质量-挠度 Pareto 前沿。
- LLM 仅预留接入位（S1 输入来源、报错诊断），未参与数值闭环，从架构隔离幻觉风险。
